# 📝 To-Do List Application

A simple, responsive, and user-friendly To-Do List Application built using **HTML, CSS, and JavaScript**. This application helps users organize daily tasks, track progress, and manage their activities efficiently.

## 🚀 Features

- **Add Tasks:** Create new tasks easily.
- **View Tasks:** Display all added tasks.
- **Edit Tasks:** Update existing tasks.
- **Delete Tasks:** Remove unwanted tasks.
- **Mark as Completed:** Track completed activities.
- **Task Filtering:** Filter tasks by All, Active, and Completed.
- **Clear Completed:** Remove all completed tasks.
- **Local Storage:** Automatically save tasks in the browser.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and responsive layout.
- JavaScript – Functionality and DOM manipulation.
- Local Storage – Persistent task storage.

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks.
